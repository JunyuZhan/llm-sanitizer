# 律师 / 法务使用指南

## 典型场景

1. **文书分析**:起诉状、判决书、证据目录交给 Agent 前,先经网关脱敏。
2. **合同审查**:用 WorkBuddy 审合同,看板实时展示被脱敏的当事人信息。
3. **批量文件**:用 `llm-sanitizer mask 文件` 对单个文件先行脱敏再交 Agent——文本/CSV/JSON/SQL/代码直接处理,docx/xlsx 保留格式(见 [开发文档 §formats](开发文档.md#formatspy))。

## 工作流建议

1. 启动网关与看板(`llm-sanitizer start`,或源码 `python3 -m llm_sanitizer start`)。
2. 接入你的 Agent(见 [AGENTS.md](AGENTS.md))。
3. 先用"含虚构信息的测试消息"验证脱敏确实发生(看板出现事件)。
4. 日常使用中定期查看看板,确认脱敏覆盖。
5. 敏感案件建议:涉及保密义务的材料,优先使用本地模型或在受控机器处理;网关只降低"明文出网"风险,不能替代保密合规。

## 重要提示

- **脱敏 ≠ 匿名化**:占位符结合上下文仍可能被推断,高敏感场景请进一步泛化(如年龄、城市、日期)。
- **映射文件保密**:`~/.llm-sanitizer/map.json` 含原文对应关系,等同敏感信息,不得外发。删除它意味着已发出的占位符无法还原。
- **CLI 与网关映射隔离**:`mask`/`restore` 使用独立映射,勿与网关映射混用,否则可能还原错误(见 [FAQ](faq.zh-CN.md#mapjson-在-cli-与网关之间混用会怎样))。
- **规则覆盖有限**:姓名、机构简称、别名可能漏检;对核心当事人建议维护自定义词表(`~/.llm-sanitizer/wordlist.txt` 或控制台"自定义敏感词表"区,词表优先于内置规则)。
- **合规**:是否可将案件材料交由第三方大模型处理,请遵守所在机构规定、律师保密义务及个人信息保护相关法规。
- **开源与信任**:本项目是 MIT 开源"中间人"网关,能读取你发给模型的内容;使用前请阅读源码与 [SECURITY 文档](SECURITY.zh-CN.md),确认符合你的信任预期。
- **免责声明**:本项目不构成法律意见,亦不提供法律合规咨询。
