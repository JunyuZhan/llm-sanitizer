# 常见问题(FAQ)

常见疑问与如实说明的限制。[English](faq.md)

## 通用

### 为什么不做成系统级代理拦截所有流量?
范围是刻意的安全决策。系统代理侵入性强(影响所有应用、可能要装证书),攻击面大得多。LLM Sanitizer 只影响显式把 `base_url` 指向网关的客户端——其他一切照旧。

### 它是防火墙吗?能拦截某些请求吗?
不是。它是**脱敏网关**,不是防火墙:它改写内容,不做允许/拒绝。阻断规则不是 v0.1 的目标。

### 支持任意大模型服务商吗?
只要暴露 OpenAI 兼容 API(Responses 或 Chat Completions)即可:OpenAI、DeepSeek、Moonshot、本地代理等。通过 `LLM_SANITIZER_UPSTREAM` 配置。

## 覆盖与限制

### WebSocket 流量能拦吗?
**v0.2 起可以。** 网关内置 WebSocket 透明代理:文本消息去程脱敏、回程还原,二进制帧(如音频)与控制帧透传。接入后请发一条含测试隐私的消息,确认看板出现脱敏事件。

### 模型会被 `[姓名_1]` 这类占位符搞糊涂吗?
大多数模型能正常处理,因为占位符自描述。少数情况模型会引用或改写占位符——此时无法还原(只做精确回填),占位符会留在响应里,但绝不会把明文泄露回上游。

### 模型能根据 `[姓名_1]` 猜出原文吗?
占位符格式原则上可猜测,但模型从未收到明文——猜测需要它根本不掌握的信息。不过**上下文**会泄密:"被告,男,30 岁,深圳"无论怎么脱敏都能缩小身份范围。这就是"脱敏 ≠ 匿名化"。

### 怎么确认脱敏真的覆盖了我的文档?
实测:发一条故意塞入样例数据的消息,然后查看看板。要全面覆盖,把正则抓不到的姓名/机构简称/别名加入**自定义词表**(控制台"自定义敏感词表"区或 `~/.llm-sanitizer/wordlist.txt`,词表优先于内置规则)。

### 能只脱敏部分类别吗?
可以(FR-15)。每条内置规则带独立类别 id,可在控制台勾选、环境变量/配置指定,或按文件 `mask --categories`。预设档:高敏感(全开)/ 办公(姓名+手机号+邮箱+公司名称+银行账号+地址)/ 自定义。**默认全量开启**;关闭某类意味着该类信息将明文出网——保存前界面会醒目提示并要求确认,看板持续显示"当前启用 N/15 类"。

### 密钥和密码也会被脱敏吗?
会,而且这是 LLM 流量网关的**最高优先级类别**。`密钥/令牌` 规则会命中常见密钥格式(`sk-...`、`ghp_...`)以及 password/token 字段,**默认开启**——当 Agent 处理配置文件、`.env` 或恰好含凭据的文档时,密钥不会出网。

## 数据与还原

### map.json 是什么?丢了会怎样?
`map.json`(位于 `~/.llm-sanitizer/`)保存原文↔占位符映射,每次请求后落盘,保证重启后 token 不漂移。删除后,已发出的占位符无法再还原——它等同敏感数据。

### map.json 在 CLI 与网关之间混用会怎样?
CLI 脱敏(`mask`/`restore`)使用**独立**映射与计数器。CLI 产生的 `[姓名_1]` 与网关产生的 `[姓名_1]` 可能指向不同的人。永远不要混用,每个工作流只用一个映射来源。

### 网关会长期保留我的明文吗?
明文只存在于三处:(1) 脱敏请求时的内存;(2) 本机磁盘上的 `map.json`(权限 600);(3) 还原后回传给 Agent 的响应。事件与日志只存占位符。

## 安全

### 它能防 prompt injection(提示注入)吗?
不能——任何文本改写类工具都不能。如果注入导致模型回显脱敏数据,模型手里只有占位符。但注入仍可能操纵 Agent 的**行为**。把网关脱敏当作一层防线,而非唯一控制。

### 网关本身是安全风险吗?
是的,设计如此:它是中间人。缓解手段:仅回环监听、零依赖、开源可审计、映射文件权限 600。它无法防御本机被完全攻陷(恶意软件)。见 [SECURITY 文档](SECURITY.zh-CN.md)。

### 如何确认我装的代码就是审计过的代码?
固定使用版本,用 release tag 对照校验和。版本固定自动化在 Roadmap 上。

## 性能与平台

### 网关会让 Agent 明显变慢吗?
脱敏是文本字段上的正则 + 字典查找,对典型文档是毫秒级。流式多一层还原缓冲。不绕路——流量仍发给同一个上游。

### 支持 Windows 吗?
**v0.3 起支持。** `pip install llm-sanitizer-gateway` 三平台通用;数据目录用 `%LOCALAPPDATA%\llm-sanitizer`(用户私有目录自带 ACL 隔离,替代 600 权限语义);开机自启用 `llm-sanitizer install`(schtasks 登录自启,免管理员)。

### 如何升级?
`pip install --upgrade llm-sanitizer-gateway` 即可;装了开机自启的话再执行 `./install.sh --uninstall && ./install.sh` 重启服务。也可以直接运行 `llm-sanitizer upgrade` 查看最新版本与升级指引(`start` 启动时也会后台检查并提示)。升级不会丢失映射与统计——`map.json` 的 token 格式稳定,旧映射升级后仍可还原。

### 支持英文/日文文档吗?
v0.1 仅中文规则。多语言规则(EN/JP)计划于 v0.3。

## 合规

### 能用它把案件材料交给云端大模型处理吗?
取决于所在机构规定、律师保密义务与适用隐私法规。网关降低的是**明文**外泄风险,并未完全消除;本项目不构成法律意见。见 [LEGAL.md](LEGAL.md)。
